# cortexkit-avatar-genome

> [!WARNING]
> **Alpha.** cortexkit-avatar-genome is in early development and is not yet released for general use.
> Breaking changes will happen between versions, including changes to its settings,
> stored data and interfaces. Pin an exact version if you depend on it.

The classic creature's 1,024-byte genome, its decoder to a typed phenotype, and genomes derived from an identifier at any length. Used by [`cortexkit-avatar`](https://crates.io/crates/cortexkit-avatar).

This crate is part of [avatar](https://github.com/cortexkit/avatar), which draws deterministic creatures from a stored genome. Licensed under MIT.
