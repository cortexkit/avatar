# cortexkit-avatar-phenotype

> [!WARNING]
> **Alpha.** cortexkit-avatar-phenotype is in early development and is not yet released for general use.
> Breaking changes will happen between versions, including changes to its settings,
> stored data and interfaces. Pin an exact version if you depend on it.

Typed fixed-point units (`Q32`, `Bam16`, `Rgb` and more) and the classic creature's phenotype, with its canonical JSON form. Used by [`cortexkit-avatar`](https://crates.io/crates/cortexkit-avatar).

This crate is part of [avatar](https://github.com/cortexkit/avatar), which draws deterministic creatures from a stored genome. Licensed under MIT.
