# cortexkit-avatar-tables

> [!WARNING]
> **Alpha.** cortexkit-avatar-tables is in early development and is not yet released for general use.
> Breaking changes will happen between versions, including changes to its settings,
> stored data and interfaces. Pin an exact version if you depend on it.

Committed lookup tables (a quarter-wave sine and easing curves) and integer helpers, so avatar generation gives the same result on every platform without calling the platform maths library. Used by [`cortexkit-avatar`](https://crates.io/crates/cortexkit-avatar).

This crate is part of [avatar](https://github.com/cortexkit/avatar), which draws deterministic creatures from a stored genome. Licensed under MIT.
